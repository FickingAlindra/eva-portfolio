# Portofolio Eva Febriyani

Situs statis dwibahasa (Indonesia/English): `index.html`, `favicon.svg`, dan folder `img/`. Tanpa build.

## Ganti gambar
Timpa file di `img/` dengan ekspor asli (lebar ±1600–2000 px) memakai **nama file yang sama**.

## Ubah teks
- Bahasa Indonesia: langsung di `index.html`.
- English: objek `EN` di bagian `<script>` bawah `index.html` (kunci sama dengan atribut `data-i18n`).
